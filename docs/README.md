# Developer Docs

This folder contains onboarding and maintenance guides for major feature areas.

Recommended reading order for a developer working on storefront checkout and tests:

1. [Guest Cart and Checkout Implementation Guide](guest-cart-checkout.md)
2. [Testing and Quality Onboarding Guide](testing-onboarding.md)

Use `guest-cart-checkout.md` to understand the product and request flow.
Use `testing-onboarding.md` to understand how the automated tests are organized, how to run them, and how to extend them safely.
